# Heart Disease Prediction API

A FastAPI application that predicts heart disease using a machine learning model.

## Features

- FastAPI
- Random Forest Classifier
- Dockerized
- Render Deployment

## Run Locally

```bash
docker-compose build
docker-compose up
```

## Swagger Documentation

[http://localhost:8000/docs](http://localhost:8000/)

## API Endpoints

GET /health

GET /info

POST /predict
